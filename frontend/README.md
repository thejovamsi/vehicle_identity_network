# DriveID 🚗

DriveID is a digital identity layer for vehicles.

Each vehicle can have a secure digital profile connected to a QR code.
People can scan the QR code to anonymously report things such as:

- Lights left on
- Parking issues
- Possible damage
- Vehicle-related incidents

The vehicle owner can receive notifications without exposing their
personal information.

## Features

- Digital vehicle profile
- QR-based vehicle identification
- Anonymous vehicle reports
- Notifications

- Privacy-focused communication
